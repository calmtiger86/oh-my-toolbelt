<h1 align="center">Oh My Toolbelt</h1>

<p align="center">
  <b>ターミナルに慣れていなくても、Claude Code を快適に。</b><br>
  よく使うプロンプトはボタンに、ファイルの添付は選択画面から、思いついたことはメモに。入力欄のすぐ上、ツールベルト一行にそろっています。
</p>

ターミナルで Claude Code を使っていると、見慣れない画面や便利機能の少なさに戸惑うことがよくあります。Oh My Toolbelt は、非開発者がターミナルを使いながら不便に感じたことを集めて作ったツールベルトです。

入力欄の上にツールベルトを一行加えるだけで、よく使うコマンドやプロンプトをボタンにしておけます。面倒だったファイルの添付も、パスを打たずに選択画面で選ぶだけです。作業中に思いついたアイデアはメモに書いておき、すぐ入力欄に取り込めます。前に送ったプロンプトも、一覧で押すだけですぐその場所に戻れます。席を外すときは**隠す**で作業内容を覆い、セッションの会話記録は**エクスポート**で一度にファイルに残せます。

ターミナルを初めて使ったときの不便を、ツールベルトひとつで減らしました。デスクトップアプリでも、ほとんどそのまま使えます。

**ターミナルから:**

```sh
claude plugin install oh-my-toolbelt --marketplace calmtiger86/oh-my-toolbelt
```

一行でインストールできます。Claude Code をすでに開いているなら、その中で `/reload-plugins` と入力すればすぐに有効になります。天気の都市を選ぶまでインターネットには接続せず、クリップボードの履歴はオンにするまで集めません。ツールベルトに書いた内容は、プロンプトとして送らない限りコンピューターの外に出ません。

**デスクトップアプリから:** **+** からプラグインの一覧を開き、リポジトリ（`calmtiger86/oh-my-toolbelt`）からマーケットプレイスを追加します。続けて一覧から oh-my-toolbelt を選んでインストールします。上のターミナルのコマンドを一度実行してもかまいません。ターミナルとデスクトップアプリのローカルセッションは同じ設定を読みます。

<details>
<summary><b>インストールの詳細: 動作環境、更新と削除</b></summary>

**必要なもの:** Claude Code 2.1.309 以降、ターミナルまたはデスクトップアプリの Code タブ。VS Code とモバイルは入力欄の上の行を描きません。

ターミナルから:

```sh
claude plugin install oh-my-toolbelt --marketplace calmtiger86/oh-my-toolbelt
```

Claude Code の中から:

```
/plugin install oh-my-toolbelt --marketplace calmtiger86/oh-my-toolbelt
```

マーケットプレイスを追加するか聞かれたら `y`、範囲は Enter を押します。続いて設定画面が出たら、各行で Enter を押して既定値のままにし、Save を押します。

更新は `claude plugin update oh-my-toolbelt` のあと Claude Code を再起動します（変更点は [CHANGELOG.md](CHANGELOG.md)、英語）。削除は `claude plugin uninstall oh-my-toolbelt` です。

</details>

## 機能

| 機能 | できること |
|---|---|
| **自分のボタン** | よく使うプロンプトやコマンドをボタンとして保存します。押すと入力欄に入れるか、そのまま送ります |
| **プロンプト一覧** | 送ったプロンプトが番号付きでたまり、押すとその場所へ移動します |
| **添付** | ファイル選択画面で選ぶと、入力欄に `@` メンションとして入ります（ターミナル） |
| **メモ** | 思いついたことを書いておき、入力欄に入れます。すべてのセッションで同じメモを使います |
| **クリップボードの履歴** | 会話からコピーした文字を集めておき、また入れられます（既定ではオフ。デスクトップアプリとターミナルの全画面表示でのみ） |
| **隠す** | 一度押すと会話を覆います |
| **エクスポート** | 会話を Markdown、HTML、テキストのファイルに保存します。ターミナルでは**状態**タブの**PDF ブラウザ**で Chromium 系のブラウザを選び、**エクスポート形式**を PDF にすれば PDF も作れます |
| **時計 · 日付 · 天気** | 時計と日付がいつも見え、都市を選ぶと天気も出ます（天気は既定ではオフ） |
| **ポモドーロ** | 集中時間を進行バーで見せ、終わると知らせます |
| **音声** | Claude Code の音声入力をオン・オフします（ターミナル） |
| **ライト / ダーク** | 画面のテーマを切り替えます |
| **折りたたみ** | `◂` を押すとツールベルト全体が `▸` 一つにたたまれます |
| **パネル** | **編集**ボタンか `/toolbelt` で開きます。設定、ボタンの配置、順を追ったガイドがあります |

## すぐに始める

1. 会話の下、入力欄のすぐ上の行がツールベルトです。
2. **編集**を押し、**ガイド**タブの 1 番に沿って試してください。2 分で終わります。
3. **状態**タブで自分好みにします。天気の都市を選び、**クリップボードタブ**をオンにし、12 時間制か 24 時間制を選びます。

![パネルのプロンプト、メモ、クリップボード、状態タブ](assets/screenshot-panel.png)

## 詳しく見る

**初めてならガイドから。** ツールベルトの**編集**を押して**ガイド**タブを開くと、機能ごとに何を押せばよいかを順を追って案内します。ガイドは設定した言語（日本語、英語、韓国語）で表示されます。

<details>
<summary><b>ツールベルトとパネルの詳細</b></summary>

### ツールベルト

左に情報、右にボタンが並びます。ウィンドウが狭いとボタンはアイコンだけに縮み、使う頻度の低いものは `…` の中に入ります。

| ツール | できること |
|---|---|
| `◂` / `▸` | ツールベルトを `▸` 一つにたたみ、また広げます。たたんだ状態は次回もそのままです |
| 時計 · 日付 | 12 時間制か 24 時間制、コンピューターのタイムゾーン、UTC、53 都市のタイムゾーンから選択、秒も表示できます。日付は言語に合った順で表示します |
| 天気 | 63 都市から一つ選ぶまではオフです。現在の天気を表示し、標準では 30 分ごとに取り直します |
| ポモドーロ | 押すと集中が始まり、もう一度押すと一時停止、さらに押すと続きます。休憩は休憩の自動開始をオンにしたときだけ計ります。1 回終わると通知が届き、オンにすれば macOS で音も鳴ります |
| 自分のボタン | 保存したプロンプトを入力欄に入れる、または送る。スラッシュコマンドやスキルを実行する。セットにまとめて切り替えられます |
| 添付 | OS のファイル選択画面を開き、選んだファイルを `@` メンションとして入力欄に入れます（ターミナル） |
| 音声 | Claude Code の音声入力をオン・オフします。`/voice` がある Claude Code で表示されます（ターミナル） |
| ライト / ダーク | Claude Code のテーマを明るい側と暗い側で切り替えます |
| 隠す | もう一度押すまで会話を覆います |
| エクスポート | 状態タブで選んだ形式で会話を保存します（最初は Markdown） |
| メモ | メモを開きます |
| 編集 | パネルを開きます |

### パネル

**編集**を押すか `/toolbelt` と入力すると、会話の横にパネルが開きます。

| タブ | 内容 |
|---|---|
| プロンプト | この会話で送ったプロンプトが番号付きですべて並びます（最新の 200 件）。押すとそのプロンプトへ移動します。ポインタを乗せると、そのターンの情報（かかった時間、使ったツール、変更したファイル）がツールベルトの行に出ます。デスクトップアプリではその場で開き、回答を最後まで読む、そのプロンプトを入力欄に戻す、その回答だけエクスポートする、ができます |
| メモ | すべてのセッションで共有するメモ帳です。挿入を押すと入力欄のカーソル位置に入ります。メモは 500 件（256 KiB）まで保存し、超えると古いものから削除します |
| クリップボード | 最初はオフです。会話をドラッグしてコピーした文が新しい順にたまり（最新の 30 件。2 万字を超える選択は集めません）、挿入で戻せます。Claude Code を閉じるまでメモリにだけあり、ファイルには書きません |
| 状態 | このセッションの要約（バージョン、天気、終えた集中の回数、最後のエラー）、すべてのツール、すべての設定をスイッチと一覧で表示します |
| ツール | レイアウト（左右、順番、表示・非表示）、自分のボタンとボタンセット、アイコンを変更します |
| ガイド | 上のすべてを順番に案内します。言語設定に従います |

</details>

<details>
<summary><b>コマンドとショートカット</b></summary>

ターミナルでは `ctrl+x` を押して離し、`tab` を押すとツールベルトが選ばれます。Tab でボタン間を移動し、Enter で押し、Esc で入力欄に戻ります。選ばれている間は、文字一つでツールを押せます（`a` 添付、`v` 音声、`t` ライト・ダーク、`h` 隠す、`e` エクスポート、`n` メモ、`b` 編集、`m` その他）。自分のボタンにも文字を割り当てられます。デスクトップアプリではボタンをクリックします。

| コマンド | できること |
|---|---|
| `/toolbelt`（ほかの mod が使っていなければ `/tb` も） | パネルを開きます |
| `/toolbelt tools` · `toc` · `notes` · `clips` · `status` · `guide` | そのタブでパネルを開きます |
| `/toolbelt toc next` · `prev` · `first` · `last` · `<番号>` · `find <語>` | プロンプトへ移動します |
| `/toolbelt pomodoro start` · `pause` · `stop` · `reset` | 開始・再開、一時停止、終了（終えた回数は残る）、リセット（終えた回数も 0 に） |
| `/toolbelt export [md\|html\|txt\|pdf]` | 会話をエクスポートします |
| `/toolbelt curtain on` · `off` | 会話を隠す、またはもう一度表示します |
| `/toolbelt weather refresh` | 天気を今すぐ取り直します |
| `/toolbelt hide` · `show` | ツールベルトを完全に隠す、または元に戻します |

</details>

<details>
<summary><b>設定</b></summary>

設定はすべてスイッチか一覧です。パネルの**状態**タブで変更でき、エクスポート形式以外は `/config` でも変更できます。

| 設定 | 既定値 | 選択肢 |
|---|---|---|
| `language` | `auto` | `auto`（システムの言語）、`en`、`ko`、`ja` |
| `clockFormat` · `clockSeconds` | `auto` · オフ | `auto`、`12`、`24`; 秒の表示オン・オフ |
| `dateFormat` | `auto` | `off`、`auto`、年が先、日が先、月が先 |
| `timeZone` | `system` | コンピューターのタイムゾーン、`UTC`、53 都市のいずれか |
| `iconStyle` | `icon+label` | `icon+label`、`icon`、`label`（絵文字が崩れるターミナル向け） |
| `weatherPlace` | `off` | `off` または 63 都市のいずれか |
| `temperatureUnit` · `weatherRefreshMinutes` | `auto` · `30` | `auto`（米国の都市は華氏）、摂氏または華氏; 10〜180 分 |
| `pomodoroFocusMinutes` · `pomodoroBreakMinutes` | `25` · `5` | 5〜120; 1〜60 |
| `pomodoroAutoBreak` · `pomodoroNotify` | オフ · オン | 集中が終わったら休憩を自動で開始（オフなら休憩は計りません）; 1 回終わるたびに通知 |
| `pomodoroSound` · `pomodoroSoundName` | オフ · `bell` | 終了時の音（macOS）: `bell`、`chime`、`ding`、`digital`、`marimba`、`soft` |
| `exportDirectory` · `pdfBrowser` | `downloads` · `off` | エクスポート先のフォルダ（`downloads`、`desktop`、`documents`、`home`、または `session`: プロジェクトフォルダなので、ファイルが git に入ることがあります）; PDF を印刷するブラウザ（`auto`、`chrome`、`edge`、`brave`、`chromium`） |
| エクスポート形式（状態タブのみ） | `md` | `md`、`html`、`txt`、`pdfBrowser` を選べばターミナルで `pdf` |
| `attachEnabled` · `voiceMode` | オン · `tap` | 添付ボタン; 音声の録音方式（`tap` または `hold`） |
| `curtainRestoreOnSubmit` | オフ | プロンプトを送ると、隠した会話をまた表示します |
| `hotkeysEnabled` | オン | ツールベルトのボタンの文字ショートカット |
| `tocTab` · `clipboardTab` | オン · オフ | プロンプトタブ; クリップボードタブ |
| `paneOpenOnStart` | オフ | セッション開始時にパネルを開きます（広いウィンドウ） |

</details>

**プライバシー:** Oh My Toolbelt はあなたのコンピューターで動き、あなたに関することを作者には何も送りません。ネットワークへの要求は、オンにしたときの天気だけです。

<details>
<summary><b>プライバシーの詳細</b></summary>

- **ネットワーク:** 天気だけで、都市を選んだあとにだけ使います。`api.open-meteo.com` が受け取るのはその都市の座標と温度の単位で、ほかのウェブの要求と同じく、IP アドレスも相手に見えます。
- **会話の内容:** プロンプトタブがオンのとき（既定）は、プロンプトの一覧を作るために、送るプロンプト、ターンごとにしたこと（ツール名、変更したファイル、かかった時間）、このセッションの会話記録ファイルを読みます。エクスポートは、あなたが求めたファイルに会話を書きます。自分で打ったコマンドは残し、その出力と、Claude Code がプロンプトの前に加えた見えない文は入れません。どちらもコンピューターの外には出ません。
- **このコンピューターに保存するもの:** ボタン、レイアウト、アイコン、メモ、ポモドーロ、天気のキャッシュ、いくつかの選択値、そしてプロンプトタブがオンの間（既定でオン）に記録した最近の 20 セッションの会話記録ファイルのパスです。Claude Code のプラグインストアに平文で置きます。クリップボード履歴はメモリにだけあります。Claude Code の実行中は、インストールしたほかの mod もメモ、ボタン、クリップボード履歴を読めます。
- **起動するプログラム:** 添付を押したときのファイル選択画面、PDF にエクスポートするときのブラウザ。また、プロンプトタブがオンのときは、このセッションの会話記録が 4 MiB を超えると、それを読むために `tail`（Windows では PowerShell）を自動で起動します。いずれもシェルを使わず、引数の一覧で起動します。
- **モデル**が見るのは、あなたが選んだものだけです。押したプロンプトボタンと、入力欄に入れたメモ、クリップ、前のプロンプト、添付したファイルだけです。`/toolbelt` コマンドの一行の返答は会話に残り、モデルが読めます。

詳しくは [PRIVACY.md](PRIVACY.md)（英語）にあります。

</details>

<details>
<summary><b>制限</b></summary>

- **デスクトップアプリ:** 添付と音声のボタンはありません（アプリの入力欄にすでにあるため）。PDF のエクスポートはなく、ポモドーロの通知はアプリ内のメッセージになります。そこでは Claude Code が mod に会話のスクロールを許さないため、プロンプトを押すと移動する代わりにその場で開きます。状態タブで変えた設定はすぐに反映され、ツールベルトが保存しておき、次にターミナルで使うときに `/config` へ書き写します。
- **クリップボードタブ:** デスクトップアプリと、Claude Code がターミナルの画面全体を描く方式（`"tui": "fullscreen"`）で集めます。inline 方式では文の選択をターミナルアプリが受け持つため、ツールベルトには何も届きません。
- **隠す**は会話を覆いますが、ロゴやお知らせのように Claude Code が自分で描く行は残ります。
- **隠す と自分のボタン:** `curtainRestoreOnSubmit` がオフのとき、動作が 送信 の自分のボタンで送ったプロンプトは隠れません（回答は隠れます）。Claude Code は、mod が送ったプロンプトの行をその mod には渡さないためです。
- **エクスポート:** Claude Code のタグの形（`<command-name>`、`<bash-stdout>` など）で始まる文は、Claude Code の出力と見分けられないため、エクスポートから外れることがあります。
- **プロンプトタブ:** プロンプトに出すターンの情報には、そのプロンプトが始めたターンだけを数えます。`!` のシェルコマンド（bash モード）の回答、自分の操作に続けて Claude Code が自動で始めるターン、ほかの mod、コマンドやスキルを実行する自分のボタン、タスクの通知が始めたターンは、どのプロンプトにも数えません。ターンの長さの記録がない古い会話では、こうしたターンも前のプロンプトに足されることがあります。
- **確認した環境:** macOS の Claude Code 2.1.309 と 2.1.310 で、ターミナルとデスクトップアプリの両方を手で確認しました。自動テストは Linux と Windows でも動きますが、そこでのファイル選択画面は手で試していません。

</details>

<details>
<summary><b>トラブルシューティング</b></summary>

- **ツールベルトが見えない?** `/plugin` を実行し、oh-my-toolbelt が有効になっているか確認してください。ウィンドウが狭いとツールベルトは縮み、およそ 14 桁より狭いと表示されなくなります。
- **何かが失敗した?** パネルの**状態**タブが最後のエラーを分かりやすい言葉で表示します。詳しい記録は `claude --debug` で Claude Code を起動すると見られます。
- **絵文字が崩れて見える?** `iconStyle` を `label` にしてください。
- **`[-]` を押したらツールベルトが消えた?** ターミナルで Claude Code 自身がたたんだものです。残った一行を押すか、`ctrl+x` のあと `ctrl+a` を押してください。
- **`ctrl+x` のあと Tab が効かない?** ターミナルアプリがそのキーを先に使っているかもしれません。`~/.claude/keybindings.json` で別のキーを割り当ててください。貼り付ける内容は**ガイド**タブの 5 番にあります。

</details>

## 開発者の方へ

Oh My Toolbelt は Claude Code の **mod** です。TypeScript（描画は JSX）で書いたフックモジュールで、エンジンがビルドなしでそのまま読み込みます。

```sh
git clone https://github.com/calmtiger86/oh-my-toolbelt
cd oh-my-toolbelt
claude --plugin-dir .          # 実行します。変更はターンが終わるたびに読み込み直されます
claude plugin validate .       # エンジンによる検査
claude plugin test .           # 500 件以上のテスト（ターミナルとデスクトップの両方）
npx -p typescript@5 tsc -p .   # 型チェック。Claude Code が一度 mod を読み込んで型を書き出したあとに使えます
```

- **構成:** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)（英語）の一枚に、モジュール、状態、ストア、エンジンが mod に求める規則をまとめています。
- **言語の追加:** `hooks/locales/en.ts` を `hooks/locales/<コード>.ts` にコピーして翻訳し、`hooks/lib/i18n.ts` と `tests/i18n.test.ts` に登録し、`.claude-plugin/plugin.json` の `language` の選択肢にコードを加えます。テストがすべてのキーとプレースホルダーの有無を確かめます。日本語はまだネイティブの確認を経ていません。直したほうがよい箇所があれば、ぜひお知らせください。
- **ツールの追加:** ツールは `hooks/tools/registry.ts` のオブジェクトです（名前、優先度、押したときの処理を効果の一覧で）。効果がエンジンの呼び出しに変わるのは `hooks/register.tsx` の一か所だけです。
- **貢献:** Issue とプルリクエストを歓迎します。コード、コメント、コミットメッセージは英語で書き、プルリクエストの前に上の三つの検査を実行してください。CI は macOS、Linux、Windows で validate とテストを実行します。
